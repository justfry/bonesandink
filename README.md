# Кости и Чернила — генератор листа персонажа

Веб-анкета для создания и развития персонажа **Ultima Forsan / SWADE**. Генератор сохраняет героев в браузере и формирует экономный двухстраничный лист A4 для печати или сохранения в PDF.

## Возможности

- пошаговое создание героя с подсказками по чертам, изъянам и снаряжению;
- повышения с автоматическим расчётом ранга SWADE;
- библиотека героев в `localStorage`, журнал изменений, импорт и экспорт JSON;
- загрузка и кадрирование портрета;
- печатный лист без фоновой заливки, с контурами дайсов характеристик;
- отдельная статическая сборка для публикации на GitHub Pages.

## Разработка

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Проверка основной сборки:

```bash
npm test
```

Статическая сборка для GitHub Pages:

```bash
npm run build:pages
```

Результат будет записан в `pages-dist/`. Публичная версия хранится в ветке `gh-pages`; изменения в `main` автоматически проверяются отдельным workflow перед следующей публикацией.
